## Vector와 Matrix 연산

#### Vector와 Matrix: 데이터를 숫자 묶음으로 보기
ONE: **Vector**는 숫자를 **한 줄로** 묶은 것이고, **Matrix**는 숫자를 **가로세로 표로** 묶은 것이에요. AI는 사진, 문장, 고객 정보를 모두 이런 숫자 묶음으로 바꿔서 계산해요.
LIKE: Vector는 고무판 위에 그린 화살표예요. (3, 2)는 "오른쪽으로 3, 위로 2"만큼 가는 화살표죠. Matrix는 그 고무판을 늘리고, 돌리고, 뒤집는 동작을 적어 둔 숫자표예요.
STEP:
1. **Scalar**: 숫자 하나. 예: 5.
2. **Vector**: 숫자를 순서대로 나열한 것. 예: (키 170, 몸무게 65, 나이 20)은 한 사람을 나타내는 3차원 Vector예요. 숫자 개수가 **차원(Dimension)**이에요.
3. 기하학적으로 Vector는 원점에서 출발하는 **화살표**예요. 방향과 길이가 있어요.
4. **Vector 더하기**: 같은 자리끼리 더해요. (1, 2) + (3, 1) = (4, 3). 화살표를 이어 붙인 것과 같아요.
5. **Scalar 곱**: 모든 숫자에 같은 수를 곱해요. 2 × (1, 2) = (2, 4). 방향은 그대로, 길이만 2배가 돼요.
6. **Matrix**: 숫자를 m행(Row) × n열(Column)의 표로 놓은 것이에요. 사람 100명의 (키, 몸무게, 나이)를 모으면 100 × 3 Matrix가 돼요.
7. **Norm (길이)**: ‖(3, 4)‖ = √(3² + 4²) = 5. 피타고라스 정리예요.
WHY: 컴퓨터는 "고양이 사진"이나 "좋아요"를 직접 이해하지 못해요. 숫자 묶음으로 바꿔야 비교하고, 계산하고, 학습할 수 있어요.
USE: 사진은 픽셀 숫자의 Matrix, 단어는 의미를 담은 Vector(Embedding), Neural Network의 한 층은 Matrix 곱셈이에요.
END: Vector는 숫자 한 줄(화살표), Matrix는 숫자 표(변환)예요. AI의 모든 데이터는 결국 이 두 가지로 표현돼요.

#### Dot Product와 Cosine Similarity
ONE: **Dot Product(내적)**는 두 Vector가 **얼마나 같은 방향을 향하는지 × 길이**를 재는 계산이고, **Cosine Similarity**는 길이는 빼고 **방향만** 비교해요.
LIKE: 두 사람이 수레를 민다고 해 봐요. 같은 방향으로 밀면 힘이 합쳐지고, 직각으로 밀면 서로 도움이 안 되고, 반대로 밀면 서로 방해해요. Dot Product는 "얼마나 같은 방향으로 미는가"를 숫자로 나타내요.
STEP:
1. **계산법**: 같은 자리끼리 곱해서 모두 더해요. (1, 2)·(3, 4) = 1×3 + 2×4 = 11.
2. **기하학적 뜻**: a·b = ‖a‖ × ‖b‖ × cosθ (θ는 두 화살표 사이의 각도).
3. 같은 방향(θ = 0°)이면 cos = 1이라 가장 커요. 직각(θ = 90°)이면 cos = 0이라 **Dot Product = 0**이에요. 이걸 **Orthogonal(직교)**이라고 해요. 반대 방향이면 음수예요.
4. **문제**: Dot Product는 길이에도 영향을 받아요. 긴 문서는 단어 수가 많아 Vector가 길어서, 내용이 덜 비슷해도 값이 커질 수 있어요.
5. **Cosine Similarity**: Dot Product를 두 길이로 나눠요. cosθ = a·b / (‖a‖ × ‖b‖). 길이 영향이 사라지고 **방향만** 남아서 −1~1 사이 값이 돼요.
6. 1이면 완전히 같은 방향(매우 비슷), 0이면 상관없음, −1이면 정반대예요.
USE: 문서·단어 Embedding의 유사도 비교, 추천 시스템("이 영화와 비슷한 영화"), 검색 엔진, AI 검색(RAG)에서 질문과 가장 비슷한 문서 찾기.
END: Dot Product = 같은 방향 정도 × 길이, Cosine Similarity = 방향만 비교. 0이면 직교예요.

#### Matrix 곱셈과 Transpose
ONE: **Matrix 곱셈**은 "**변환을 순서대로 적용**"하는 것이라 순서를 바꾸면 결과가 달라져요(AB ≠ BA). **Transpose**는 행과 열을 맞바꾼 것이에요.
LIKE: "양말 신고 신발 신기"와 "신발 신고 양말 신기"의 결과가 다르듯, Matrix 곱도 순서가 중요해요. 그리고 벗을 때는 신발부터 벗어야 하죠. 이게 (AB)ᵀ = BᵀAᵀ, (AB)⁻¹ = B⁻¹A⁻¹의 느낌이에요.
STEP:
1. **곱하는 방법**: AB의 (i, j) 칸 = A의 i번째 행과 B의 j번째 열의 Dot Product.
2. **크기 조건**: A가 m×n, B가 n×p일 때만 곱할 수 있고 결과는 m×p예요. A의 열 수와 B의 행 수가 같아야 해요.
3. **Matrix × Vector**: Ax는 "Vector x에 변환 A를 적용한 결과"예요.
4. **ABx의 뜻**: B를 먼저 적용하고, 그다음 A를 적용해요(오른쪽부터).
5. **교환법칙 없음**: 회전한 뒤 반사하는 것과 반사한 뒤 회전하는 것은 결과가 달라요. 게다가 크기가 안 맞아 BA가 아예 정의되지 않을 수도 있어요.
6. **결합법칙·분배법칙은 성립**: (AB)C = A(BC), A(B + C) = AB + AC.
7. **Transpose (Aᵀ)**: 행과 열을 바꿔요. 2×3 Matrix의 Transpose는 3×2예요. 그리고 (AB)ᵀ = BᵀAᵀ처럼 순서가 뒤집혀요.
8. **Identity Matrix (I)**: 대각선은 1, 나머지는 0인 Matrix예요. 숫자의 1처럼 AI = IA = A예요.
KEY: Dot Product를 Matrix로 쓰면 aᵀb예요. Neural Network의 Backpropagation에서는 Gradient를 Transpose한 Matrix로 거꾸로 곱하는 계산이 계속 나와요.
END: Matrix 곱은 변환을 순서대로 적용하는 것이라 순서가 중요해요. Transpose는 행·열 바꾸기이고, 곱의 Transpose는 순서가 뒤집혀요.

### Vector의 Dot Product(내적)는 무엇을 재나요? Cosine Similarity와는?
E: 두 사람이 같은 방향으로 밀면 힘이 합쳐지고, 직각으로 밀면 서로 도움이 안 되고, 반대로 밀면 서로 방해합니다. Dot Product는 "두 화살표가 얼마나 같은 방향을 향하는가 × 길이"입니다.
A: Dot Product는 a·b = Σ aᵢbᵢ = ‖a‖‖b‖cosθ로, 두 Vector의 길이(Norm)와 방향의 일치 정도를 함께 재며 0이면 Orthogonal(직교)입니다. Cosine Similarity는 Dot Product를 두 길이로 나눈 cosθ = a·b / (‖a‖‖b‖)로, 길이 영향을 없애고 방향만 비교해 −1~1 사이 값을 갖습니다. 문서·단어 Embedding의 유사도를 잴 때 널리 씁니다.

### Matrix Multiplication은 왜 교환법칙(AB = BA)이 성립하지 않나요?
E: "양말 신고 신발 신기"와 "신발 신고 양말 신기"의 결과가 다르듯, Matrix 곱은 동작을 순서대로 적용하는 것이라 순서가 중요합니다.
A: Matrix는 Linear Transformation이고 ABx는 "B를 먼저, 그다음 A"를 적용하는 합성(Composition)이므로, 회전 후 반사와 반사 후 회전처럼 순서가 바뀌면 결과가 달라질 수 있습니다. 또 A가 m×n, B가 n×p이면 AB는 정의되어도 BA는 크기가 맞지 않아 정의조차 안 될 수 있습니다. 단, 결합법칙(Associativity) (AB)C = A(BC)와 분배법칙(Distributivity)은 성립합니다.

### Transpose와 (AB)ᵀ = BᵀAᵀ의 의미는?
A: Transpose(전치행렬) Aᵀ는 Row와 Column을 바꾼 Matrix(Aᵀᵢⱼ = Aⱼᵢ)입니다. (AB)ᵀ = BᵀAᵀ는 뒤집으면 곱의 순서가 반대가 된다는 뜻으로, Dot Product를 xᵀy로 쓰고 Backpropagation에서 Gradient를 Transpose해 거꾸로 곱할 때 계속 등장합니다. Inverse Matrix도 같은 꼴로 (AB)⁻¹ = B⁻¹A⁻¹입니다(양말을 신고 신발을 신었다면 벗을 때는 신발부터).

## 연립방정식과 Gaussian Elimination

#### Gaussian Elimination (가우스 소거법)
ONE: 연립방정식에서 **식끼리 빼고 더해 변수를 하나씩 지워 가며** 푸는 방법이에요. Matrix로 정리하면 컴퓨터가 체계적으로 풀 수 있어요.
LIKE: "사과 2개 + 배 1개 = 5천 원", "사과 1개 + 배 1개 = 3천 원"이 있을 때, 위 식에서 아래 식을 빼면 "사과 1개 = 2천 원"이 바로 나와요. 그걸 넣으면 배는 1천 원이에요. 식끼리 빼서 변수를 지우는 게 핵심이에요.
STEP:
1. 연립방정식을 Matrix로 써요. 2x + y = 5, x + y = 3은 계수 Matrix A = [[2, 1], [1, 1]]과 b = (5, 3), 즉 Ax = b예요.
2. A와 b를 나란히 붙인 **Augmented Matrix(첨가행렬)** [A | b]를 만들어요.
3. **기본 행 연산 3가지**: ① 두 행 바꾸기 ② 한 행에 0이 아닌 수 곱하기 ③ 한 행의 몇 배를 다른 행에 더하기. 이 연산들은 해를 바꾸지 않아요.
4. 이 연산으로 왼쪽 아래를 0으로 만들어 계단 모양(**Echelon Form**)을 만들어요.
5. 각 행에서 처음 나오는 0이 아닌 수를 **Pivot**이라고 해요.
6. 더 나아가 Pivot을 모두 1로, Pivot 위아래를 모두 0으로 만들면 **RREF(기약행 사다리꼴)**예요. 해를 바로 읽을 수 있고, 한 Matrix의 RREF는 하나로 정해져요.
7. 예: [[2, 1 | 5], [1, 1 | 3]]에서 정리하면 x = 2, y = 1.
WHY: 변수가 수천 개인 연립방정식도 같은 절차로 풀 수 있어요. 컴퓨터가 연립방정식을 푸는 기본 방법이에요.
END: 식끼리 빼서 변수를 지우고 계단 모양을 만들면 해가 보여요. 행 연산은 해를 바꾸지 않아요.

#### 해가 없음 · 하나 · 무수히 많음
ONE: Echelon Form을 보면 해의 개수를 알 수 있어요. **"0 = 0이 아닌 수"가 나오면 해 없음**, **모든 변수에 Pivot이 있으면 해 하나**, **Pivot 없는 변수가 있으면 해가 무수히 많아요**.
LIKE: 직선 두 개를 생각해 보세요. 평행하면 만나지 않고(해 없음), 엇갈리면 한 점에서 만나고(해 하나), 완전히 겹치면 모든 점에서 만나요(해 무수히 많음).
STEP:
1. Augmented Matrix를 Echelon Form으로 만들어요.
2. **해 없음 (Inconsistent)**: [0 0 … 0 | c] (c ≠ 0) 같은 행이 나오면 "0 = c"라는 모순이에요. 해가 없어요.
3. 모순이 없으면 해가 있어요(**Consistent**).
4. **해 하나**: 모든 변수 Column에 Pivot이 있어요. 각 변수가 하나로 정해져요.
5. **해 무수히 많음**: Pivot이 없는 변수 Column이 있어요. 이 변수를 **Free Variable(자유변수)**이라고 하고, 아무 값이나 넣을 수 있어서 해가 무수히 많아요.
| 경우 | Echelon Form의 모습 |
| 해 없음 | [0 0 … 0 \| c] (c ≠ 0) 행이 나옴 |
| 해 하나 | 모순 없음 + 모든 변수에 Pivot |
| 해 무수히 많음 | 모순 없음 + Free Variable 있음 |
END: 모순 행이 있으면 해 없음, Free Variable이 있으면 무수히 많음, 둘 다 없으면 해 하나예요.

#### Ax = 0과 Ax = b의 관계
ONE: **Ax = 0**의 해들을 **Ax = b의 해 하나만큼 평행이동**하면 Ax = b의 모든 해가 돼요.
LIKE: 원점을 지나는 직선(Ax = 0의 해들)을 통째로 들어 옮겨, 점 p를 지나게 놓은 것이 Ax = b의 해들이에요. 모양은 같고 위치만 달라요.
STEP:
1. **Homogeneous (동차) Ax = 0**: x = 0은 항상 해예요(**Trivial Solution, 자명해**).
2. Free Variable이 있을 때만 0이 아닌 해(**Nontrivial Solution**)가 있어요.
3. **Non-Homogeneous Ax = b**: 해가 있다면, 그중 하나를 p라고 해요(특수해).
4. 그러면 Ax = b의 모든 해는 **x = p + vₕ**예요. vₕ는 Ax = 0의 아무 해나요.
5. 이유: A(p + vₕ) = Ap + Avₕ = b + 0 = b.
6. 기하학적으로는 원점을 지나는 Ax = 0의 해집합(선이나 평면)을 p만큼 평행이동한 것이에요.
END: Ax = b의 해 = 특수해 하나 + Ax = 0의 모든 해. 모양은 같고 위치만 옮긴 거예요.

### Gaussian Elimination과 RREF(Reduced Row Echelon Form)란?
E: "사과 2개와 배 1개가 5천 원, 사과 1개와 배 1개가 3천 원"에서 아래 식을 위 식에서 빼면 사과 1개 = 2천 원이 바로 나오듯, 식끼리 빼고 더해 변수를 하나씩 지우는 방법입니다.
A: Gaussian Elimination(가우스 소거법)은 Row 교환, 0이 아닌 수 곱하기, 한 Row의 배수를 다른 Row에 더하기라는 세 가지 Elementary Row Operation(기본 행 연산)으로 해를 바꾸지 않고 Matrix를 계단 모양(Echelon Form)으로 만드는 방법입니다. RREF(기약행 사다리꼴)는 각 Pivot(Row의 첫 0이 아닌 수)이 1이고 Pivot이 있는 Column의 나머지가 모두 0인 형태로, 해를 바로 읽을 수 있고 한 Matrix에 대해 유일합니다.

### 해가 없음 / 하나 / 무수히 많음을 Pivot으로 어떻게 판별하나요?
| 경우 | Augmented Matrix [A \| b]를 Echelon Form으로 만든 모습 |
| 해 없음 (Inconsistent) | [0 0 … 0 \| c] (c ≠ 0) Row가 나옴 = 마지막(b) Column에 Pivot |
| 해 하나 | 해가 있고, 모든 변수 Column에 Pivot (Free Variable 없음) |
| 해 무수히 많음 | 해가 있고, Pivot 없는 변수 Column(Free Variable)이 하나 이상 |
A: Augmented Matrix(첨가행렬)를 Echelon Form으로 만들었을 때 "0 = 0이 아닌 수" 꼴의 Row가 생기면 모순이라 해가 없고, 그렇지 않으면 해가 있습니다(Consistent). 해가 있을 때 모든 변수에 Pivot이 있으면 해가 유일하고, Pivot이 없는 Free Variable(자유변수)이 있으면 그 변수를 아무 값으로나 정할 수 있어 해가 무수히 많습니다.

### Ax = 0(Homogeneous)과 Ax = b(Non-Homogeneous) 해의 관계는?
A: Ax = 0은 x = 0이라는 Trivial Solution(자명해)이 항상 있고, Free Variable이 있을 때만 Nontrivial Solution(비자명해)이 있습니다. Ax = b가 해 p를 하나 갖는다면 전체 해는 x = p + vₕ(vₕ는 Ax = 0의 임의의 해)입니다. 기하적으로는 원점을 지나는 Homogeneous 해집합을 p만큼 평행이동(Translation)한 것입니다.

## Linear Independence·Span·Basis·Dimension

#### Linear Combination과 Span
ONE: **Linear Combination(선형 결합)**은 Vector들에 숫자를 곱해 더한 것이고, **Span**은 그렇게 만들 수 있는 **모든 Vector의 모음**이에요.
LIKE: 물감 빨강·파랑·노랑을 각각 얼마씩 섞으면 여러 색이 나와요. 섞는 방법 하나가 Linear Combination이고, 그 세 물감으로 만들 수 있는 모든 색의 집합이 Span이에요.
STEP:
1. **Linear Combination**: c₁v₁ + c₂v₂ + … + cₖvₖ. 각 Vector에 숫자(계수)를 곱해 더해요.
2. 예: v₁ = (1, 0), v₂ = (0, 1)이면 3v₁ + 2v₂ = (3, 2). 사실 이 두 Vector로 평면의 모든 점을 만들 수 있어요.
3. **Span{v₁, …, vₖ}**: 가능한 모든 Linear Combination의 집합이에요.
4. Vector 하나의 Span은 원점을 지나는 **직선**이에요(길이만 바꿀 수 있으니까요).
5. 방향이 다른 두 Vector의 Span은 원점을 지나는 **평면**이에요.
6. "Ax = b가 해를 갖는가?"는 "b가 A의 Column들의 Span 안에 있는가?"와 같은 질문이에요.
END: 곱해서 더하면 Linear Combination, 그렇게 만들 수 있는 전부가 Span이에요.

#### Linear Independence (선형 독립)
ONE: Vector들 중 **어느 것도 나머지를 섞어서 만들 수 없으면** Linearly Independent(독립)이고, 하나라도 만들 수 있으면 Dependent(종속)예요.
LIKE: 동쪽 화살표와 북쪽 화살표는 서로를 대신할 수 없어서 독립이에요. 여기에 북동쪽 화살표를 더하면, 그건 이미 동쪽 + 북쪽으로 만들 수 있으니 군더더기(종속)예요.
STEP:
1. **정의**: c₁v₁ + … + cₖvₖ = 0을 만족하는 계수가 **모두 0인 경우뿐**이면 독립이에요.
2. 0이 아닌 계수로 0을 만들 수 있다면, 그중 한 Vector를 나머지로 표현할 수 있으니 종속이에요.
3. **확인 방법**: Vector들을 Column으로 놓은 Matrix를 Echelon Form으로 만들어요. **모든 Column에 Pivot**이 있으면 독립이에요.
4. **빠른 판단 ①**: 0 Vector가 하나라도 있으면 종속이에요.
5. **빠른 판단 ②**: m차원 공간에서 m개보다 많은 Vector는 항상 종속이에요. 평면(2차원)에 화살표 3개를 놓으면 하나는 반드시 나머지로 만들 수 있어요.
WHY: 독립인 Vector들만 남기면 정보가 중복 없이 깔끔해져요. 데이터의 Feature가 서로 종속이면(예: 키(cm)와 키(m)를 둘 다 넣음) Regression이 불안정해져요.
END: 서로 대신할 수 없으면 독립, 하나라도 나머지로 만들 수 있으면 종속이에요.

#### Basis와 Dimension
ONE: **Basis(기저)**는 공간 전체를 만들 수 있으면서(Span) **군더더기가 없는(독립)** Vector 묶음, 즉 **최소한의 좌표축 세트**예요. Basis의 개수가 **Dimension(차원)**이에요.
LIKE: 지도에서 어떤 장소든 "동쪽으로 몇 칸, 북쪽으로 몇 칸"으로 말할 수 있어요. 동쪽·북쪽 두 방향이 평면의 Basis이고, 그래서 평면은 2차원이에요.
STEP:
1. **Basis의 두 조건**: ① 공간 전체를 Span한다(모든 Vector를 만들 수 있음) ② Linearly Independent하다(군더더기 없음).
2. 그래서 공간의 모든 Vector를 Basis로 **정확히 한 가지 방법**으로 표현할 수 있어요. 그 계수가 **좌표**예요.
3. **Standard Basis**: R²에서는 (1, 0)과 (0, 1), R³에서는 (1,0,0), (0,1,0), (0,0,1).
4. Basis는 여러 가지일 수 있어요. (1, 1)과 (1, −1)도 R²의 Basis예요.
5. 하지만 **Basis Vector의 개수는 항상 같아요**. 그 개수가 Dimension이에요. R³는 3차원.
WHY: 같은 데이터도 좋은 Basis를 고르면 훨씬 단순하게 표현돼요. PCA는 데이터를 가장 잘 설명하는 새 Basis를 찾는 방법이에요.
END: Basis = 공간을 다 만들 수 있는 최소 좌표축 세트, Dimension = 그 개수예요.

### Linear Independence(선형 독립)란? 어떻게 확인하나요?
E: 동쪽·북쪽 화살표는 서로 대신할 수 없으므로 독립입니다. 여기에 북동쪽 화살표를 더하면, 이미 동쪽+북쪽으로 만들 수 있어서 군더더기(Dependent, 종속)입니다.
A: Vector v₁, …, vₖ가 Linearly Independent라는 것은 c₁v₁ + … + cₖvₖ = 0을 만드는 계수가 모두 0뿐인 것, 즉 어느 Vector도 나머지의 Linear Combination으로 만들 수 없는 것입니다. Vector들을 Column으로 놓은 Matrix를 Echelon Form으로 만들어 모든 Column에 Pivot이 있으면 독립이며, Rᵐ에서 m개보다 많은 Vector는 항상 종속입니다.

### Basis(기저)와 Dimension(차원)은?
A: Basis는 공간을 Span(생성)하면서 Linearly Independent인 Vector 집합, 즉 공간의 모든 Vector를 정확히 한 가지 방법으로 표현하게 해 주는 "최소의 좌표축 세트"입니다. Basis는 여러 가지일 수 있지만 Basis Vector의 개수는 항상 같고, 그 개수가 Dimension입니다(R³는 3차원).

## Linear Transformation

#### Linear Transformation과 Matrix
ONE: **Linear Transformation**은 **직선은 직선으로, 원점은 제자리에** 두면서 공간을 늘리고 돌리고 뒤집는 변환이에요. 모든 Linear Transformation은 **Matrix 하나로** 표현돼요.
LIKE: 격자무늬 고무판을 늘리거나 돌려도 격자선이 곧고 평행하며 고르게 유지되고, 원점은 그대로 있는 변형이에요. 그래서 기본 화살표(축) 두어 개가 어디로 가는지만 알면 나머지 전체가 정해져요.
STEP:
1. **조건**: T(u + v) = T(u) + T(v), T(cu) = cT(u). 더하고 나서 변환하나, 변환하고 나서 더하나 결과가 같아요.
2. 모든 Vector는 기본 축(Standard Basis) e₁, e₂, …의 Linear Combination이에요. 예: (3, 2) = 3e₁ + 2e₂.
3. 그래서 T(3e₁ + 2e₂) = 3T(e₁) + 2T(e₂). **기본 축이 어디로 가는지만 알면** 모든 Vector의 결과를 알 수 있어요.
4. T(e₁), T(e₂), …를 Column으로 나란히 놓은 Matrix A를 만들면, **T(x) = Ax**예요.
5. 예: 90° 반시계 회전은 e₁ = (1, 0)을 (0, 1)로, e₂ = (0, 1)을 (−1, 0)으로 보내요. 그래서 Matrix는 [[0, −1], [1, 0]].
USE: Computer Graphics의 회전·확대·이동(게임 화면), 이미지 변환, Neural Network의 각 층(입력 Vector에 Weight Matrix를 곱함).
END: Linear Transformation은 격자를 곧게 유지하는 변형이고, 기본 축의 도착지를 Column으로 모으면 그 Matrix가 돼요.

#### One-to-One과 Onto
ONE: 변환 T(x) = Ax가 **서로 다른 입력을 같은 출력으로 보내지 않으면 One-to-One(단사)**, **모든 출력을 만들 수 있으면 Onto(전사)**예요. Pivot 위치로 판별해요.
LIKE: One-to-One은 "두 사람이 같은 자리에 앉지 않는" 좌석 배정이고, Onto는 "빈 자리가 하나도 없는" 좌석 배정이에요(01번 주제의 Function과 같은 뜻이에요).
STEP:
1. A가 m×n Matrix면 T는 n차원 입력을 m차원 출력으로 보내요.
2. **One-to-One**: Ax = 0의 해가 x = 0 하나뿐이에요. 즉 Column들이 Linearly Independent, **모든 Column에 Pivot**.
3. 이유: 두 입력 u, v가 같은 출력이면 A(u − v) = 0이에요. 0이 아닌 해가 없으면 u = v일 수밖에 없어요.
4. **Onto**: 모든 b에 대해 Ax = b의 해가 있어요. 즉 Column들이 Rᵐ 전체를 Span, **모든 Row에 Pivot**.
5. 열이 행보다 많으면(n > m) One-to-One일 수 없고, 행이 열보다 많으면(m > n) Onto일 수 없어요.
END: Column마다 Pivot이면 One-to-One(겹침 없음), Row마다 Pivot이면 Onto(빈자리 없음)예요.

### Linear Transformation이란? 모든 Linear Transformation이 Matrix로 표현되는 이유는?
E: Linear Transformation은 격자 무늬 고무판을 늘리거나 돌려도 격자선이 곧고 평행하며 고르게 유지되고 원점은 제자리에 있는 변형입니다. 그래서 기본 화살표(축) 두어 개가 어디로 가는지만 알면 전체가 정해집니다.
A: Linear Transformation은 T(u + v) = T(u) + T(v), T(cu) = cT(u)를 만족하는 함수입니다. 모든 Vector는 Standard Basis e₁, …, eₙ의 Linear Combination이므로 선형성(Linearity)에 따라 T(x)는 T(e₁), …, T(eₙ)만으로 결정되고, 이들을 Column으로 놓은 Standard Matrix A = [T(e₁) … T(eₙ)]에 대해 T(x) = Ax가 됩니다.

### One-to-One(단사)·Onto(전사) Transformation을 Matrix로 판별하는 법은?
A: m×n Matrix A에 대해 T(x) = Ax가 One-to-One(서로 다른 입력이 같은 출력으로 가지 않음)인 것은 Ax = 0이 Trivial Solution만 갖는 것, 즉 Column들이 Linearly Independent이고 모든 Column에 Pivot이 있는 것과 같습니다. Onto(모든 Rᵐ Vector가 출력으로 나옴)인 것은 Column들이 Rᵐ을 Span하는 것, 즉 모든 Row에 Pivot이 있는 것과 같습니다.

## Subspace와 Rank

#### Column Space와 Null Space
ONE: **Column Space**는 변환 A로 **만들 수 있는 모든 출력**이고, **Null Space**는 변환이 **0으로 눌러 없애 버리는 입력들**이에요.
LIKE: 물감 세 가지(Matrix의 Column)를 섞어 만들 수 있는 모든 색이 Column Space이고, 섞었는데 결과가 "아무 색도 없음"이 되는 배합법들이 Null Space예요.
STEP:
1. **Subspace**: 원점을 포함하고, 더하기와 Scalar 곱을 해도 그 안에 머무는 Vector 모음이에요. 원점을 지나는 직선이나 평면 같은 것들이에요.
2. **Column Space (Col A)**: A의 Column들의 Span이에요. Ax = b가 해를 갖는 b들의 집합이에요.
3. Col A의 Basis는 원래 A의 **Pivot Column들**이에요(Echelon Form의 Column이 아니라 원래 Matrix의 Column이라는 점에 주의).
4. **Null Space (Nul A)**: Ax = 0의 모든 해예요. 변환하면 0이 되는 방향들이에요.
5. Null Space가 {0}뿐이면 아무것도 사라지지 않으니 변환은 One-to-One이에요.
END: Column Space는 "만들 수 있는 것", Null Space는 "0으로 사라지는 것"이에요.

#### Rank와 Rank-Nullity Theorem
ONE: **Rank**는 변환 후 **살아남는 차원 수**(Pivot 개수), **Nullity**는 **0으로 눌려 사라지는 차원 수**(Free Variable 개수)이고, 둘을 더하면 **입력 차원 수(Column 개수)**예요.
LIKE: 3차원 물체에 위에서 빛을 비춰 바닥에 그림자를 만들면, 가로·세로 2차원은 그림자에 살아남고(Rank 2), 높이 1차원은 사라져요(Nullity 1). 합치면 원래 3차원이에요.
STEP:
1. **Rank**: Column Space의 Dimension = Pivot의 개수.
2. **Nullity**: Null Space의 Dimension = Free Variable의 개수.
3. 모든 Column은 Pivot Column이거나 Free Variable Column 둘 중 하나예요.
4. 그래서 **rank + nullity = n (Column 개수)**.
5. 예: 3×5 Matrix의 Rank가 3이면 Nullity는 5 − 3 = 2.
6. 뜻: 입력 n차원 중 일부는 출력으로 살아남고(Rank), 나머지는 0으로 눌려 사라진다는 **차원 보존 법칙**이에요.
WHY: Rank는 데이터에 "진짜로 독립인 정보가 몇 차원 있는가"를 알려 줘요. 데이터를 압축할 때(Low-Rank 근사) 핵심 개념이에요.
END: 살아남는 차원(Rank) + 사라지는 차원(Nullity) = 입력 차원(Column 수)이에요.

### Column Space와 Null Space란?
E: 물감 세 가지(Matrix의 Column)를 섞어 만들 수 있는 모든 색이 Column Space이고, 섞었는데 결과가 "아무 색도 없음"이 되는 배합법들이 Null Space입니다.
A: Column Space(열공간) Col A는 A의 Column들의 모든 Linear Combination, 즉 Ax = b가 해를 갖는 b들의 집합이며, Basis는 원래 A의 Pivot Column들입니다. Null Space(영공간) Nul A는 Ax = 0의 모든 해로, 변환이 0으로 만들어 버리는 방향들입니다. Null Space가 {0}뿐이면 변환은 One-to-One입니다.

### Rank-Nullity Theorem(rank + nullity = Column 개수)의 의미는?
A: Rank는 Column Space의 Dimension(Pivot 개수), Nullity는 Null Space의 Dimension(Free Variable 개수)이며, 모든 Column은 Pivot Column이거나 Free Variable Column이므로 둘의 합은 Column 개수 n입니다. 입력 n차원 중 일부는 출력으로 살아남고(Rank) 나머지는 0으로 눌려 사라진다(Nullity)는 차원 보존 법칙입니다. 예를 들어 3×5 Matrix의 Rank가 3이면 Nullity는 2입니다.

## Inverse Matrix와 Determinant

#### Inverse Matrix와 Invertible Matrix Theorem
ONE: **Inverse Matrix A⁻¹**는 변환 A를 **되돌리는** 변환이에요(AA⁻¹ = I). 공간을 납작하게 눌러 버리는 변환은 되돌릴 수 없어서 Inverse가 없어요.
LIKE: 고무판을 늘리거나 돌린 것은 되돌릴 수 있지만, 종이처럼 납작하게 눌러 버린 것은 원래 모양을 알 수 없어 되돌릴 수 없어요.
STEP:
1. **Invertible (가역)**: AA⁻¹ = A⁻¹A = I인 A⁻¹가 있어요. 정사각 Matrix에서만 생각해요.
2. Inverse가 있으면 Ax = b의 해를 x = A⁻¹b로 바로 구할 수 있어요.
3. **Singular (비가역)**: Inverse가 없어요. 공간을 더 낮은 차원으로 눌러서 정보가 사라졌기 때문이에요.
4. **Invertible Matrix Theorem**: n×n Matrix A에서 다음은 **모두 같은 말**이에요. 하나만 확인하면 나머지가 다 따라와요.
5. A가 Invertible ⇔ det A ≠ 0 ⇔ Pivot이 n개 ⇔ Column들이 Linearly Independent ⇔ Column들이 Rⁿ 전체를 Span ⇔ Ax = 0의 해가 0뿐 ⇔ 모든 b에 대해 Ax = b의 해가 유일 ⇔ rank A = n ⇔ 0이 Eigenvalue가 아님.
KEY: 실제 계산에서는 A⁻¹를 직접 구하기보다 Gaussian Elimination 같은 방법으로 Ax = b를 바로 푸는 게 더 빠르고 정확해요.
END: Inverse는 "되돌리기"이고, 납작하게 누르지 않는(det ≠ 0) 변환만 되돌릴 수 있어요.

#### Determinant (행렬식)
ONE: **Determinant**는 변환이 **넓이(또는 부피)를 몇 배로 바꾸는지**를 나타내는 숫자예요. 0이면 공간이 납작하게 눌려 되돌릴 수 없어요.
LIKE: 고무판 위에 넓이 1인 정사각형을 그리고 변환해 보세요. 변환 뒤 그 도형의 넓이가 6이 되면 Determinant는 6이에요. 거울처럼 뒤집히면 앞에 −가 붙어요.
STEP:
1. **2×2 계산**: [[a, b], [c, d]]의 Determinant = ad − bc.
2. 예: [[2, 0], [0, 3]]은 가로 2배, 세로 3배로 늘리니 넓이가 6배. det = 2×3 − 0×0 = 6.
3. **부호**: 음수면 방향이 뒤집힌 거예요(거울상).
4. **det = 0**: 넓이가 0이 됐다는 뜻이에요. 평면이 선으로(또는 점으로) 눌려 정보가 사라졌어요. 그래서 Inverse가 없고(Singular), Ax = b는 해가 없거나 무수히 많아요.
5. **곱셈 성질**: det(AB) = det A × det B. "두 번 늘리면 배율이 곱해진다"는 뜻이에요.
WHY: det 하나로 "이 변환을 되돌릴 수 있나?"를 알 수 있고, Eigenvalue를 구하는 식(det(A − λI) = 0)에도 쓰여요.
END: Determinant = 넓이(부피) 배율. 0이면 납작해져서 되돌릴 수 없어요.

### 어떤 Matrix가 Invertible(가역)인가요? (Invertible Matrix Theorem)
E: Invertible은 "되돌릴 수 있다"입니다. 고무판을 늘리거나 돌린 것은 되돌릴 수 있지만, 종이처럼 납작하게 눌러 버린 것은 원래 모양을 알 수 없어 되돌릴 수 없습니다.
A: n×n Matrix A가 Invertible이라는 것은 AA⁻¹ = A⁻¹A = I인 A⁻¹가 있다는 뜻이며, 다음은 모두 같은 말입니다: det A ≠ 0, Pivot이 n개, Column들이 Linearly Independent, Column들이 Rⁿ을 Span, Ax = 0이 Trivial Solution만 가짐, 모든 b에 대해 Ax = b의 해가 유일, rank A = n, 0이 Eigenvalue가 아님. 하나만 확인해도 나머지가 모두 따라옵니다.

### Determinant(행렬식)의 기하학적 의미는? det = 0이면?
A: Determinant는 변환이 넓이(2차원)나 부피(3차원)를 몇 배로 바꾸는지를 나타내고, 부호는 방향(Orientation)이 뒤집혔는지(거울상)를 나타냅니다. det = 0이면 공간이 더 낮은 차원(평면→선)으로 눌려 정보가 사라지므로 Inverse가 없고(Singular), Ax = b는 해가 없거나 무수히 많습니다. det(AB) = det A · det B는 "두 번 늘리면 배율이 곱해진다"는 뜻입니다.

## Eigenvalue·Eigenvector·Diagonalization

#### Eigenvalue와 Eigenvector
ONE: **Eigenvector**는 변환해도 **방향이 바뀌지 않고 길이만 변하는** 특별한 Vector이고, 그 길이 배율이 **Eigenvalue**예요. 변환의 "주된 축"을 알려 줘요.
LIKE: 고무판을 늘리면 대부분의 화살표는 방향이 틀어져요. 그런데 어떤 화살표는 같은 방향을 유지한 채 길이만 변해요. 그 화살표가 Eigenvector이고, 몇 배가 됐는지가 Eigenvalue예요.
STEP:
1. **정의**: Av = λv (v ≠ 0). A를 곱해도 v의 방향은 그대로, 길이만 λ배.
2. λ > 1이면 늘어나고, 0 < λ < 1이면 줄어들고, λ < 0이면 반대 방향으로 뒤집히고, λ = 0이면 0으로 눌려요.
3. 예: A = [[2, 1], [1, 2]]. A(1, 1) = (3, 3) = 3(1, 1)이니 (1, 1)은 Eigenvalue 3의 Eigenvector예요.
4. 같은 A에서 A(1, −1) = (1, −1)이니 (1, −1)은 Eigenvalue 1의 Eigenvector예요.
5. 그러면 이 변환은 "(1, 1) 방향으로 3배 늘이고, (1, −1) 방향은 그대로 두기"로 아주 단순하게 이해돼요.
WHY: 복잡한 변환을 "축 방향으로 늘이기"로 쪼개서 이해할 수 있어요. 변환이 반복될 때 어디로 수렴하는지도 알려 줘요.
USE: PCA(데이터가 가장 많이 퍼진 방향 = Covariance Matrix의 Eigenvector), Google PageRank와 Markov Chain의 장기 상태(Eigenvalue 1의 Eigenvector), 진동·안정성 분석.
END: Eigenvector = 방향이 안 바뀌는 화살표, Eigenvalue = 그 화살표의 늘어난 배율이에요.

#### Characteristic Equation: Eigenvalue 구하기
ONE: Eigenvalue는 **det(A − λI) = 0**을 풀어서 구해요. 이 식은 "A − λI가 공간을 납작하게 누른다"는 조건이에요.
LIKE: "방향이 안 바뀌는 화살표가 있다"는 건, 그 화살표를 0으로 보내는 변환(A − λI)이 있다는 뜻이고, 무언가를 0으로 보내려면 공간이 눌려야(det = 0) 해요.
STEP:
1. Av = λv를 옮기면 Av − λv = 0, 즉 **(A − λI)v = 0**.
2. 이 식에 v ≠ 0인 해가 있으려면, A − λI가 0이 아닌 Vector를 0으로 보내야 해요. 즉 A − λI가 Singular여야 해요.
3. Singular ⇔ Determinant가 0. 그래서 **det(A − λI) = 0**. 이게 **Characteristic Equation(특성 방정식)**이에요.
4. 이 λ에 대한 n차 다항식의 근이 Eigenvalue예요.
5. 각 λ를 (A − λI)v = 0에 넣어 풀면 Eigenvector가 나와요.
6. 예: A = [[2, 1], [1, 2]]면 det(A − λI) = (2 − λ)² − 1 = 0 → λ = 3 또는 1.
KEY: 확인용 성질: Eigenvalue들의 **합 = Trace(대각선 합)**, **곱 = Determinant**. 위 예에서 3 + 1 = 4 = 2 + 2, 3 × 1 = 3 = 2×2 − 1×1.
END: det(A − λI) = 0을 풀면 Eigenvalue, 그 λ로 (A − λI)v = 0을 풀면 Eigenvector예요.

#### Diagonalization (대각화)
ONE: 독립인 Eigenvector가 충분히 있으면 **A = PDP⁻¹**로 쓸 수 있어요. Eigenvector 좌표계에서 보면 변환이 **축별로 늘이기만 하는 대각 Matrix D**가 돼서 계산이 아주 쉬워져요.
LIKE: 비스듬히 놓인 고무판을 그대로 보면 복잡하게 늘어나는 것 같지만, 고무판을 돌려서 고유 방향에 맞춰 보면 그냥 "가로로 3배, 세로로 1배" 늘이는 단순한 변환이에요.
STEP:
1. **P**: Eigenvector들을 Column으로 놓은 Matrix. **D**: Eigenvalue들을 대각선에 놓은 Matrix.
2. **A = PDP⁻¹**의 뜻: P⁻¹로 Eigenvector 좌표계로 바꾸고 → D로 축별로 늘이고 → P로 원래 좌표계로 돌아와요.
3. **조건**: n×n Matrix에 Linearly Independent한 Eigenvector가 n개 있어야 해요.
4. Eigenvalue가 모두 다르면 항상 가능해요. 같은 Eigenvalue가 겹쳐도 가능할 수 있지만 항상은 아니에요.
5. **유용한 점**: Aᵏ = PDᵏP⁻¹. 대각 Matrix의 거듭제곱은 대각선 숫자만 거듭제곱하면 돼서, A¹⁰⁰도 쉽게 계산돼요.
USE: 반복되는 과정(인구 변화, Markov Chain)의 장기 예측, 미분방정식 풀기, Fibonacci 수열의 일반항 구하기.
END: 대각화는 "고유 방향으로 돌려 보면 그냥 늘이기"예요. 덕분에 거듭제곱이 쉬워져요.

### Eigenvalue와 Eigenvector가 무엇이고 왜 중요한가요?
E: 고무판을 늘리면 대부분의 화살표는 방향이 틀어지지만, 어떤 화살표는 같은 방향을 유지한 채 길이만 변합니다. 그 화살표가 Eigenvector이고, 길이가 몇 배 되었는지가 Eigenvalue입니다. 변환의 "주된 축"을 알려 주는 것이죠.
A: Eigenvector(고유벡터)는 Av = λv(v ≠ 0)를 만족하는 Vector, 즉 변환해도 방향이 그대로이고 λ배만 되는 Vector이며 λ가 Eigenvalue(고유값)입니다. 복잡한 변환을 고유축 방향의 단순한 늘이기로 분해해 주므로, PCA(Covariance Matrix의 Eigenvector = Principal Component), PageRank·Markov Chain의 Steady State(Eigenvalue 1의 Eigenvector), Matrix의 거듭제곱 계산, 시스템 안정성 분석에 쓰입니다.
M: A = [[2, 1], [1, 2]]이면 det(A − λI) = (2 − λ)² − 1 = 0에서 λ = 3, 1입니다. λ = 3의 Eigenvector는 (1, 1), λ = 1의 Eigenvector는 (1, −1)이며, 실제로 A(1, 1) = (3, 3), A(1, −1) = (1, −1)입니다.

### Characteristic Equation det(A − λI) = 0은 어디서 나오나요?
A: Av = λv를 옮기면 (A − λI)v = 0이고, 이 식이 v ≠ 0인 해를 가지려면 A − λI가 비가역(Singular)이어야 하므로 det(A − λI) = 0입니다. 이 λ에 대한 n차 다항식의 근이 Eigenvalue이고, 각 λ를 넣어 (A − λI)v = 0을 풀면 Eigenvector가 나옵니다. Eigenvalue의 합은 Trace(대각합), 곱은 Determinant와 같습니다.

### Diagonalization(A = PDP⁻¹)은 언제 가능하고 왜 유용한가요?
A: n×n Matrix는 Linearly Independent인 Eigenvector가 n개 있을 때 Diagonalizable하며, Eigenvalue가 모두 다르면 항상 가능합니다(중복 Eigenvalue가 있어도 가능할 수 있음). P의 Column은 Eigenvector, D의 대각은 Eigenvalue이고, Eigenvector 좌표계에서 보면 변환이 축별 늘이기로 단순해집니다. 그래서 Aᵏ = PDᵏP⁻¹처럼 거듭제곱을 대각원소의 거듭제곱으로 쉽게 계산할 수 있습니다.

## Orthogonality와 Least Squares

#### Orthogonal Projection (직교 투영)
ONE: Vector를 어떤 직선이나 평면에 **수직으로 그림자를 떨어뜨린** 것이 Projection이에요. 그 그림자는 평면 위에서 **원래 Vector와 가장 가까운 점**이에요.
LIKE: 한낮에 해가 수직으로 비출 때 막대기가 바닥에 만드는 그림자예요. 그림자 끝은 바닥 위에서 막대기 끝과 가장 가까운 점이에요.
STEP:
1. **Orthogonal (직교)**: 두 Vector의 Dot Product가 0이면 서로 수직이에요.
2. Vector y를 Subspace W에 Projection하면 y = ŷ + z로 나뉘어요. ŷ는 W 안의 그림자, z는 W에 수직인 나머지예요.
3. 이렇게 나누는 방법은 **딱 하나**예요.
4. **ŷ는 W 안에서 y와 가장 가까운 점**이에요. 수직으로 내린 거리가 가장 짧으니까요.
5. **한 방향 u로의 Projection**: ŷ = (y·u / u·u) u. 예: y = (3, 4)를 u = (1, 0) 방향에 Projection하면 (3, 0).
6. W가 서로 수직인 Basis(Orthogonal Basis)를 가지면, 각 Basis 방향의 Projection을 더하면 돼요.
WHY: "정확히 맞출 수는 없을 때 가장 가까운 답"을 찾는 모든 문제(Least Squares)의 기하학적 원리예요.
END: Projection은 수직으로 내린 그림자이고, 그림자는 평면 위에서 가장 가까운 점이에요.

#### Gram-Schmidt Process와 QR Decomposition
ONE: 아무 Basis에서나 출발해 **서로 수직인 Basis**를 만드는 방법이 Gram-Schmidt이고, 이걸 Matrix로 표현한 것이 **A = QR** 분해예요.
LIKE: 비스듬히 기운 기둥들을 하나씩 세우면서, 앞에서 세운 기둥 방향으로 기운 부분을 깎아 내 모든 기둥이 서로 직각이 되게 만드는 거예요.
STEP:
1. 첫 Vector는 그대로 첫 번째 축으로 써요.
2. 두 번째 Vector에서 첫 번째 축 방향 성분(Projection)을 빼요. 남은 부분은 첫 축에 수직이에요.
3. 세 번째 Vector에서 앞의 두 축 방향 성분을 모두 빼요. 이걸 계속해요.
4. 이렇게 만든 Vector들은 서로 수직(**Orthogonal Basis**)이고, 원래와 같은 공간을 Span해요.
5. 각 Vector의 길이를 1로 맞추면(Normalize) **Orthonormal Basis**가 돼요.
6. **QR Decomposition**: Column이 독립인 Matrix A를 A = QR로 써요. Q는 Orthonormal Column들, R은 위쪽 삼각 Matrix(Upper Triangular)예요.
USE: Least Squares를 수치적으로 안정적으로 풀 때, Eigenvalue를 계산하는 QR Algorithm에 써요.
END: 앞 방향 성분을 차례로 빼면 서로 수직인 축이 생겨요(Gram-Schmidt). 이걸 Matrix로 쓰면 A = QR이에요.

#### Least Squares: 가장 가까운 해
ONE: 해가 없는 Ax = b에서, **오차의 제곱합이 가장 작은 x**를 찾는 방법이에요. 데이터에 가장 잘 맞는 직선을 긋는 **Linear Regression**이 바로 이 문제예요.
LIKE: 점들을 정확히 모두 지나는 직선은 없지만, 각 점에서 직선까지의 세로 거리를 제곱해 더한 값이 가장 작은 직선은 있어요.
STEP:
1. 데이터가 많으면 Ax = b의 식이 변수보다 훨씬 많아서 정확한 해가 없는 경우가 대부분이에요. b가 A의 Column Space 밖에 있는 거예요.
2. 그래서 ‖Ax − b‖²(오차 제곱합)을 가장 작게 만드는 x̂를 찾아요. 이게 **Least Squares Solution**이에요.
3. 기하학적으로 Ax̂는 b를 Column Space에 **Projection**한 점이에요(가장 가까운 점).
4. 그러면 오차 b − Ax̂는 Column Space에 수직이라서 Aᵀ(b − Ax̂) = 0이에요.
5. 정리하면 **Normal Equation: AᵀAx̂ = Aᵀb**. Column이 독립이면 x̂ = (AᵀA)⁻¹Aᵀb.
6. **OLS Regression**: A를 데이터 Matrix X, b를 정답 y로 두면 β̂ = (XᵀX)⁻¹Xᵀy예요. "공부 시간으로 점수 예측하기"의 가장 기본 공식이에요(14번 주제).
KEY: 제곱을 쓰는 이유: 양수·음수 오차가 서로 지워지지 않고, 미분하기 쉬워서 위처럼 깔끔한 공식이 나와요. 대신 큰 오차(이상치)에 민감해요.
END: 정확한 해가 없으면 오차 제곱합을 최소로. 답은 Projection이고, 공식은 Normal Equation AᵀAx̂ = Aᵀb예요.

### Orthogonal Projection(직교 투영)이란?
E: 한낮에 해가 수직으로 비출 때 막대기가 바닥에 만드는 그림자입니다. 그림자는 바닥 위에서 막대기 끝과 가장 가까운 점입니다.
A: Vector y를 Subspace W에 Orthogonal Projection하면 y = ŷ + z(ŷ는 W 안, z는 W에 수직)로 유일하게 나뉘고, ŷ는 W 안에서 y와 가장 가까운 점입니다. 한 Vector u 방향으로의 Projection은 ŷ = (y·u / u·u)u이고, W가 Orthogonal Basis를 가지면 각 Basis 방향 Projection을 더하면 됩니다.

### Gram-Schmidt Process와 QR Decomposition은 무엇을 만드나요?
A: Gram-Schmidt는 Basis Vector에서 앞서 만든 Vector 방향 성분(Projection)을 차례로 빼서 같은 공간의 Orthogonal Basis를 만들고, 길이를 1로 맞추면(Normalize) Orthonormal Basis가 됩니다. Column이 Linearly Independent인 Matrix A에 이를 적용하면 A = QR(Q는 Orthonormal Column, R은 Invertible인 Upper Triangular Matrix)로 분해되며, Least Squares를 수치적으로 안정적으로 푸는 데 쓰입니다.

### 해가 없는 Ax = b에서 "가장 가까운 해"는? Normal Equation과 OLS의 관계는?
E: 점들을 정확히 모두 지나는 직선은 없지만, 각 점에서 직선까지의 세로 거리를 제곱해 더한 값이 가장 작은 직선은 있습니다.
A: b가 Column Space 밖에 있으면 ‖Ax − b‖²을 최소화하는 Least Squares Solution x̂를 구하며, Ax̂는 b를 Column Space에 Projection한 점입니다. 그러면 Residual(잔차) b − Ax̂가 모든 Column에 수직이므로 Aᵀ(b − Ax̂) = 0, 즉 Normal Equation(정규방정식) AᵀAx̂ = Aᵀb가 나오고, Column이 독립이면 x̂ = (AᵀA)⁻¹Aᵀb입니다. OLS(Ordinary Least Squares) Regression은 A를 Data Matrix X, b를 정답 y로 둔 같은 문제로 β̂ = (XᵀX)⁻¹Xᵀy입니다(14 Machine Learning 참고).

## Symmetric Matrix·SVD·Positive Definite

#### Symmetric Matrix와 Spectral Theorem
ONE: **Symmetric Matrix(Aᵀ = A)**는 Eigenvalue가 모두 실수이고, **서로 수직인 Eigenvector**로 항상 대각화할 수 있어요(A = PDPᵀ).
LIKE: 대칭인 고무판 변형은 항상 서로 직각인 두(또는 세) 방향으로만 늘이고 줄이는 변형으로 설명돼요. 비스듬한 축이 필요 없어요.
STEP:
1. **Symmetric Matrix**: 대각선을 기준으로 거울처럼 대칭이에요. Aᵢⱼ = Aⱼᵢ.
2. **Spectral Theorem**: 실수 Symmetric Matrix는 ① Eigenvalue가 모두 실수 ② 서로 다른 Eigenvalue의 Eigenvector는 서로 수직 ③ 서로 수직이고 길이 1인 Eigenvector n개를 항상 고를 수 있어요.
3. 그래서 **A = PDPᵀ**로 쓸 수 있어요. P가 Orthogonal Matrix라 P⁻¹ = Pᵀ(Inverse 계산이 Transpose로 끝나요).
4. 반대로, 이렇게 Orthogonal Diagonalization이 되는 Matrix는 반드시 Symmetric이에요.
5. **Covariance Matrix**(데이터의 변수끼리 얼마나 같이 변하는지 담은 Matrix)는 항상 Symmetric이에요.
USE: PCA는 Covariance Matrix를 이 정리로 분해해서, 서로 수직인 주성분(Principal Component)을 찾아요(14번 주제).
END: 대칭 Matrix는 서로 수직인 고유 방향으로 항상 깔끔하게 분해돼요. PCA가 가능한 이유예요.

#### SVD (Singular Value Decomposition)
ONE: **모든 Matrix**는 **"회전 → 축별로 늘이기 → 다시 회전"** 세 단계로 분해할 수 있어요. 이게 SVD, A = UΣVᵀ예요.
LIKE: 어떤 이상한 고무판 변형이든, "먼저 판을 돌리고, 가로세로로 늘이고, 다시 돌리는" 세 동작으로 똑같이 만들 수 있다는 거예요.
STEP:
1. **A = UΣVᵀ**. Vᵀ는 첫 회전(·반사), Σ는 축별 늘이기, U는 두 번째 회전(·반사)이에요.
2. U와 V는 Orthogonal Matrix(회전·반사), Σ는 대각선에 0 이상의 **Singular Value** σ₁ ≥ σ₂ ≥ … 를 놓은 Matrix예요.
3. Singular Value는 AᵀA의 Eigenvalue의 제곱근이에요.
4. **Eigendecomposition과의 차이**: 대각화는 정사각 Matrix이고 조건을 만족할 때만 되지만, SVD는 **직사각 Matrix를 포함해 모든 Matrix**에 존재해요.
5. **Low-Rank Approximation**: 큰 Singular Value k개만 남기고 나머지를 0으로 하면, 원래 Matrix에 가장 가까운 Rank-k Matrix가 돼요(Eckart-Young Theorem). 중요한 정보만 남기고 압축하는 거예요.
USE: 이미지 압축(큰 Singular Value 몇 개만으로 사진을 거의 복원), 추천 시스템(사용자 × 영화 평점 Matrix를 분해), PCA 계산, 검색의 LSA, 노이즈 제거.
END: SVD는 모든 Matrix를 "회전·늘이기·회전"으로 쪼개요. 큰 Singular Value만 남기면 최고의 압축이 돼요.

#### Positive Definite Matrix (양의 정부호 행렬)
ONE: Symmetric Matrix A가 0이 아닌 모든 x에 대해 **xᵀAx > 0**이면 Positive Definite예요. 어느 방향으로든 **위로 휘어진 그릇 모양**이라서 **최솟값이 확실히** 있어요.
LIKE: 그릇 바닥에 구슬을 놓으면 어느 방향으로 굴러가든 결국 가장 낮은 한 점으로 모여요. Positive Definite는 이런 "어느 쪽으로든 올라가는 그릇" 모양이에요.
STEP:
1. **정의**: 0이 아닌 모든 x에 대해 xᵀAx > 0.
2. **같은 말**: A의 Eigenvalue가 모두 양수.
3. f(x) = xᵀAx를 그리면 모든 방향으로 위로 휘어진 그릇 모양이에요. 바닥(최솟값)이 딱 하나예요.
4. **Optimization에서의 의미**: 함수의 Gradient가 0인 점에서 **Hessian**(2차 미분 Matrix)이 Positive Definite이면, 그 점은 **Local Minimum**이에요.
5. Hessian이 어디서나 Positive Definite이면 함수가 **Strictly Convex**라서 최솟값이 하나뿐이에요. 어디서 출발해도 Gradient Descent가 그 한 점을 찾아요.
6. Eigenvalue 중 양수와 음수가 섞이면 말안장 모양(**Saddle Point**)이에요.
WHY: Machine Learning의 학습은 Loss를 최소화하는 Optimization이에요. 그릇 모양인지 아닌지가 학습이 쉬운지 어려운지를 정해요.
END: Positive Definite = 모든 Eigenvalue가 양수 = 어느 쪽으로든 올라가는 그릇. 최솟값이 확실해요.

### Symmetric Matrix는 왜 항상 Orthogonal Diagonalization이 가능한가요?
A: Spectral Theorem에 따르면 실수 Symmetric Matrix(Aᵀ = A)는 Eigenvalue가 모두 실수이고, 서로 다른 Eigenvalue의 Eigenvector는 서로 Orthogonal하며, Orthonormal Eigenvector n개를 항상 고를 수 있어 A = PDPᵀ(P⁻¹ = Pᵀ)로 쓸 수 있습니다. 반대로 Orthogonal Diagonalization이 되는 Matrix는 반드시 Symmetric입니다. Covariance Matrix가 Symmetric이라 서로 수직인 Principal Component를 얻는 PCA가 이 정리 덕분에 가능합니다.

### SVD(Singular Value Decomposition)란? Eigendecomposition과 무엇이 다른가요?
E: 어떤 변환이든 "돌리기 → 축별로 늘리기 → 다시 돌리기" 세 단계로 나눌 수 있다는 것입니다.
A: SVD는 모든 m×n Matrix를 A = UΣVᵀ로 분해하며, U·V는 Orthogonal Matrix(회전·반사), Σ는 0 이상의 Singular Value σᵢ(AᵀA Eigenvalue의 제곱근)를 대각에 둔 Matrix입니다. Eigendecomposition은 정사각 Matrix이고 Diagonalizable할 때만 되지만 SVD는 직사각 Matrix를 포함해 항상 존재합니다. 큰 Singular Value k개만 남기면 가장 가까운 Rank-k 근사(Low-Rank Approximation)가 되어(Eckart-Young Theorem) PCA, 이미지 압축, 추천 시스템, LSA에 쓰입니다.

### Positive Definite Matrix(양의 정부호 행렬)란? Optimization에서 왜 중요한가요?
A: Symmetric Matrix A가 0이 아닌 모든 x에 대해 xᵀAx > 0이면 Positive Definite이고, 이는 Eigenvalue가 모두 양수인 것과 같습니다. xᵀAx가 어느 방향으로든 위로 휘어진 그릇 모양이므로, Gradient가 0인 점에서 Hessian이 Positive Definite이면 그 점은 Local Minimum(극소점)이고, Hessian이 어디서나 Positive Definite이면 함수가 Strictly Convex(순볼록)라 최솟값이 하나뿐입니다.

## Matrix Calculus (Backpropagation의 기초)

#### Gradient · Jacobian · Hessian
ONE: **Gradient**는 함수가 **가장 가파르게 증가하는 방향**, **Jacobian**은 Vector 함수의 **변화율을 모은 Matrix**, **Hessian**은 **휘어짐(곡률)**을 나타내는 2차 미분 Matrix예요.
LIKE: 안개 낀 산에서 발밑의 경사를 느끼는 게 Gradient(가장 가파른 오르막 방향)이고, 그 경사가 얼마나 빨리 변하는지(오목한지 볼록한지)를 느끼는 게 Hessian이에요.
STEP:
1. **Partial Derivative (편미분)**: 변수가 여러 개일 때, 하나만 조금 움직이고 나머지는 고정했을 때의 변화율이에요.
2. **Gradient ∇f**: f: Rⁿ → R(입력 여러 개, 출력 하나)의 편미분을 모은 Vector예요. 가장 가파르게 증가하는 방향을 가리켜요.
3. 그래서 Loss를 줄이려면 **Gradient의 반대 방향**으로 조금씩 움직여요. 이게 **Gradient Descent**예요.
4. **Jacobian**: f: Rⁿ → Rᵐ(입력 여러 개, 출력 여러 개)일 때, Jᵢⱼ = ∂fᵢ/∂xⱼ인 m×n Matrix예요. 입력을 조금 바꾸면 출력이 어떻게 변하는지의 선형 근사예요.
5. **Hessian**: 2차 편미분을 모은 n×n Matrix예요. 그릇처럼 오목한지, 말안장처럼 휘었는지를 알려 줘요.
USE: Gradient는 모든 Neural Network 학습의 기본이고, Hessian은 Optimizer 분석과 2차 최적화 방법(Newton's Method)에 써요.
END: Gradient = 가장 가파른 오르막 방향, Jacobian = 다변수 변화율 표, Hessian = 휘어짐이에요.

#### Chain Rule과 Backpropagation
ONE: 함수를 여러 번 합성했을 때의 미분은 **각 단계의 미분(Jacobian)을 곱한 것**이에요(Chain Rule). Neural Network는 층을 여러 번 합성한 함수라서, 이걸 **출력부터 거꾸로** 계산하는 게 Backpropagation이에요.
LIKE: 톱니바퀴 세 개가 맞물려 있을 때, 첫 바퀴를 1바퀴 돌리면 둘째는 2바퀴, 둘째가 1바퀴 돌 때 셋째는 3바퀴 돈다면, 첫 바퀴 1바퀴에 셋째는 2 × 3 = 6바퀴 돌아요. 단계별 배율을 곱하는 게 Chain Rule이에요.
STEP:
1. **1변수 Chain Rule**: h(x) = g(f(x))면 h'(x) = g'(f(x)) × f'(x).
2. **Matrix 버전**: J_h(x) = J_g(f(x)) × J_f(x). 각 단계의 Jacobian을 Matrix 곱셈해요.
3. Neural Network는 입력 → 1층 → 2층 → … → 출력 → Loss로 이어진 긴 합성 함수예요.
4. 각 Weight가 Loss에 얼마나 영향을 주는지(Gradient) 알려면, Loss에서 그 Weight까지 거꾸로 Chain Rule을 적용해야 해요.
5. **Backpropagation**: 출력 쪽부터 각 층의 Jacobian(의 Transpose)을 차례로 곱하며 Gradient를 앞쪽 층으로 전달해요. 한 번 계산한 중간 결과를 재사용해서 매우 효율적이에요.
6. 층이 깊을 때 이 곱셈에서 1보다 작은 수가 계속 곱해지면 Gradient가 거의 0이 되고(**Vanishing Gradient**), 1보다 큰 수가 계속 곱해지면 폭발해요(**Exploding Gradient**)(15번 주제).
END: 합성 함수의 미분은 단계별 미분의 곱이고, 그걸 출력에서 거꾸로 전달하는 게 Backpropagation이에요.

### Gradient, Jacobian, Hessian이란?
E: 안개 낀 산에서 발밑의 경사를 느끼는 것이 Gradient(가장 가파른 오르막 방향), 경사가 얼마나 빨리 변하는지(오목한지 볼록한지)를 느끼는 것이 Hessian입니다.
A: Scalar 함수 f: Rⁿ → R의 Gradient ∇f는 Partial Derivative(편미분)를 모은 Vector로 가장 가파르게 증가하는 방향을 가리키고, Hessian은 2차 편미분의 n×n Matrix로 Curvature(곡률)를 나타냅니다. Vector 함수 f: Rⁿ → Rᵐ의 Jacobian은 Jᵢⱼ = ∂fᵢ/∂xⱼ인 m×n Matrix로, 입력을 조금 바꿀 때 출력이 어떻게 변하는지를 선형 근사합니다.

### Chain Rule을 Matrix로 쓰면 어떻게 되나요?
A: 합성 함수 h(x) = g(f(x))의 Jacobian은 Jₕ(x) = J_g(f(x)) · J_f(x)로, 각 단계의 Jacobian을 Matrix Multiplication한 것입니다. Neural Network는 Layer를 여러 번 합성한 함수이므로, Scalar Loss의 Gradient를 출력 쪽부터 각 Layer Jacobian의 Transpose를 차례로 곱하며 거꾸로 전달하는 것이 Backpropagation입니다(15 Deep Learning 참고).
